# SQUISH! — Bounce Back Adventure

A small, playable 2D browser platform game built with HTML, CSS and vanilla JavaScript Canvas.

## Run the game
1. Extract `SQUISH.zip`.
2. Open `index.html` in Chrome, Firefox, Edge or another modern browser.
3. Click **LET'S PLAY**.

No installation, server, Godot or build step is required. An internet connection is only used for the optional Google Fonts import; the game itself runs locally.

## Controls
- Left / Right arrows or A / D: move
- Space / Up arrow / W: jump
- Down arrow / S: squish and charge a stronger bounce while on the ground
- P or Escape: pause

On touch devices, on-screen controls are available below the game.

## Included
- Five themed worlds
- Platform jumping and squish-powered bounce charging
- Collectible crystals, hazards and patrolling enemies
- Final boss encounter in the Sky Kingdom
- Level unlock progression and saved crystal totals using browser localStorage
- Sound toggle and responsive menus

## Notes
This is the first complete playable release, designed as a compact browser game. It uses original canvas-drawn placeholder art rather than external sprite packs. Progress is saved in the browser on the device where you play.
